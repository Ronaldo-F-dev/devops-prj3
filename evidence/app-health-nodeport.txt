Acces externe via NodePort - Jour 4, Projet 5

Service : kps-tasks-api, type NodePort, port 8000 -> nodePort 30080

Depuis une machine externe au VPS (pas de tunnel SSH, requete HTTP directe) :

$ curl http://169.58.11.221:30080/health
{"status":"ok","database":"ok","version":"1.0.0","details":null}

$ curl http://169.58.11.221:30080/version
{"name":"KPS Tasks API","version":"1.0.0","environment":"production"}

$ curl http://169.58.11.221:30080/tasks
[{"title":"Test Kubernetes","description":"Creee depuis le pod k8s Jour 3","status":"todo","id":1,
  "created_at":"2026-08-14T09:12:38.933821Z","updated_at":"2026-08-14T09:12:38.933821Z"}]

-> L'application deployee dans Kubernetes est accessible depuis l'exterieur
   du cluster ET depuis l'exterieur du VPS, via le NodePort 30080 -- sans
   passer par le port 8000 utilise par l'ancien deploiement Docker Compose
   (Projet 4), qui continue de tourner en parallele pendant la migration.
